Enable accessibility

Android requires you to turn on RC Agent accessibility manually. This is what lets the agent read the screen and tap for you.

On Poco: Accessibility → Downloaded apps → RC Agent. If the app is sideloaded, first allow restricted settings from App info → ⋮.
